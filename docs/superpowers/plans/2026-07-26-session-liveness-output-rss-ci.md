# Session Liveness, Compact Output, RSS, and CI Implementation Plan

> **Execution rule:** Do not run Cargo build, test, Clippy, benchmark, or release
> commands on the local Raspberry Pi. GitHub Actions is the authoritative build
> and test host. Local validation is limited to source inspection, diffs, and
> rustfmt.

**Goal:** Prevent an MCP instance from wedging before request dispatch, isolate
SSH reuse between Codex tasks, reduce empty-request memory retention, compact
`remote_hosts`, and shorten CI while preserving the existing remote operation
semantics.

**Architecture:** Keep one persistent helper session per host inside each MCP
process. Give each `SshRunner` a private OpenSSH connection namespace, bound all
pre-dispatch locks and session setup with the configured connect deadline, and
remove abandoned single-flight state on failure. Allocate output previews only
after bytes arrive. Preserve text-first MCP rendering.

**Tech stack:** Rust 1.91.1, Tokio, OpenSSH, MCP JSON-RPC, GitHub Actions.

## Task 2: Bound session acquisition and cleanup

**Files:**

- Modify: `src/ssh/process.rs`
- Modify: `src/ssh/session.rs`
- Modify: `src/error.rs` only if an existing timeout constructor cannot express
  the setup failure

**Steps:**

1. Introduce a small helper that converts `connect_timeout_ms` into one absolute
   Tokio deadline and returns the existing `CONNECT_TIMEOUT` error.
2. Use that deadline when acquiring the host capability initializer.
3. Use it again for the session single-flight wait and the entire
   `HostSession::connect_with_capability` future.
4. Make cancellation win promptly at every wait.
5. Ensure a leader error or cancellation drops the guard and removes any
   abandoned generation before returning.
6. Bound helper status, helper upload, handshake, child termination, and child
   drain under the same connection-attempt deadline. Do not await `kill` or
   `wait` without a remaining-time bound.
7. Preserve the safe retry boundary: connection modes may fall back only before
   a request frame is submitted; no command is replayed after submission.
8. Confirm errors retain host, shell, root, and mutation ambiguity context.
9. Run local `cargo fmt --all` only.

## Task 3: Isolate OpenSSH reuse per MCP instance

**Files:**

- Modify: `src/ssh/mod.rs`
- Modify: `src/ssh/process.rs`
- Modify: `tests/ssh_transport.rs`
- Modify: `tests/real_ssh.rs`
- Modify: `docs/security.md`
- Modify: `docs/performance.md`

**Steps:**

1. Generate a runner-instance nonce from process identity, current time, and a
   process-local atomic sequence. The runtime directory is already private
   mode 0700, so this is an isolation identifier rather than a secret.
2. Store the nonce on `SshRunner`.
3. Include it in the hashed `ControlPath`; never expose alias, resolved
   identity, or nonce in the filename.
4. Set `ControlPersist=5`.
5. Preserve stable reuse for every policy generated by the same runner.
6. Update real-SSH cleanup assertions to allow one private master per runner,
   never one global master shared by independent runners.
7. Update security and performance documentation with the task-isolation and
   cold/warm behavior.
8. Run local `cargo fmt --all` only.
